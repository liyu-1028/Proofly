## 截图规范

- **格式**：PNG（无压缩或最小压缩）
- **分辨率**：1440 × 900 起步，2x 适配
- **主题**：使用真实数据脱敏后的演示数据
- **风格**：清屏状态、避免个人信息
- **命名**：`{序号}-{功能}.png`，全小写英文

## 引用方式

在 README.md 中通过相对路径引用：

```markdown
![工作台](docs/screenshots/03-dashboard.png)
```
